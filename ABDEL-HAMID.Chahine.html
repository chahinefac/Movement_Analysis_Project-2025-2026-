1. Context

The stretch-shortening cycle (SSC) is a fundamental component of force production in dynamic movements. It consists of a rapid eccentric phase immediately followed by a concentric contraction, allowing the storage and reutilization of elastic energy and improving force production. In vertical jumping, the SSC contributes to performance by increasing jump height when a countermovement is performed before take-off. This explains why the Countermovement Jump (CMJ) generally produces greater jump height than the Squat Jump (SJ), which is performed from a static position and relies mainly on concentric force production.

However, in pathological conditions affecting the lower limb, such as patellar tendinopathy, movement strategies may be altered. Previous work by Ben Zaki and colleagues (2025) has shown that athletes with patellar tendinopathy can modify their jumping and landing mechanics, particularly at the knee, suggesting adaptations in the way force is produced and absorbed during explosive tasks.

Therefore, comparing SJ and CMJ performance may provide insight into whether the functional contribution of the stretch-shortening cycle is preserved in individuals with patellar tendinopathy.

2. Aim

The aim of this project was to compare jump height between Squat Jump (SJ) and Countermovement Jump (CMJ) in individuals with patellar tendinopathy, using the difference in performance between both jump modalities as an indirect indicator of stretch-shortening cycle contribution.

3. Hypothesis

It was hypothesized that jump height would be greater in the CMJ condition than in the SJ condition. This difference was interpreted as an indirect functional indicator of SSC contribution.

4. Methods

Participants

The sample included 12 high-level athletes diagnosed with patellar tendinopathy. Each participant performed both jump conditions, which justified a within-subject paired analysis.

Outcome measure

The primary outcome extracted from each file was Jump Height (Flight Time) [cm]. Only the Mean value was retained for each condition.

Jump height derived from flight time estimates the vertical displacement of the center of mass during the airborne phase, assuming ballistic motion and equivalent center of mass position at take-off and landing.

Formula:

h = (t² × g) / 8

6.1 Data extraction and cleaning

This section extracts the variable Jump Height (Flight Time) [cm] from each participant folder inside the data/ directory. Only the files SJ.xlsx and CMJ.xlsx were used.

Because the Excel files exported from the force-platform software contained additional formatting and metadata, the raw files could not be analyzed directly. A custom Python function was therefore implemented to automatically identify the row containing the true variable headers and reconstruct a clean dataframe before extraction.

The script then searched specifically for the variable Jump Height (Flight Time) [cm] and extracted the corresponding Mean value for each jump condition. Only the mean value was retained in order to obtain one representative value per participant for both SJ and CMJ conditions.

All extracted values were converted into numeric format and merged into a paired dataframe containing one row per participant and two variables:

  • SJ_Mean
  • CMJ_Mean

This cleaned dataset was finally exported as Global_Jump_Height.xlsx and used for the subsequent statistical analysis performed in R.

Show Python code 
import os
import pandas as pd

#----- Creation of the dataframe -----

# Folder containing one subfolder per participant
data_folder = "data"

# Function used to rebuild the dataframe with the correct headers
def read_clean_df(file_path):
    df = pd.read_excel(file_path, header=None)

    # Find the row containing the true headers ("Name")
    header_row = df[df.apply(lambda row: row.astype(str).str.contains("Name").any(), axis=1)].index[0]

    # Rebuild the dataframe using the detected header row
    df.columns = df.iloc[header_row]
    df = df.iloc[header_row + 1:].reset_index(drop=True)

    return df

# List used to store the final cleaned values
data = []

# Browse all participant folders
for patient in os.listdir(data_folder):
    patient_path = os.path.join(data_folder, patient)

    # Ignore files that are not folders
    if not os.path.isdir(patient_path):
        continue

    # Store one value for each jump condition
    values = {"SJ_Mean": None, "CMJ_Mean": None}

    # Read only SJ and CMJ files
    for file in ["SJ.xlsx", "CMJ.xlsx"]:
        file_path = os.path.join(patient_path, file)

        # Skip if the expected file does not exist
        if not os.path.exists(file_path):
            continue

        try:
            df = read_clean_df(file_path)

            # Select the row corresponding to Jump Height
            row = df[df["Name"] == "Jump Height (Flight Time) [cm]"]

            # Extract the Mean value
            mean_value = float(row["Mean"].iloc[0])

            # Store the value according to the jump condition
            if file == "SJ.xlsx":
                values["SJ_Mean"] = mean_value
            elif file == "CMJ.xlsx":
                values["CMJ_Mean"] = mean_value

        except Exception as e:
            print(f"Error with {file_path}: {e}")

    # Add participant data only if both conditions are available
    if values["SJ_Mean"] is not None and values["CMJ_Mean"] is not None:
        values["Participant"] = patient
        data.append(values)

# Create the final dataframe
df_final = pd.DataFrame(data)

# Reorder columns
df_final = df_final[["Participant", "SJ_Mean", "CMJ_Mean"]]

# Export the cleaned dataset
df_final.to_excel("data/Global_Jump_Height.xlsx", index=False)

# Display the final dataframe
df_final

7.6 Normality of paired differences

Because the main inferential test planned in this project is a paired Student t-test, we first need to verify whether the paired differences are approximately normally distributed.

Importantly, the normality assumption is tested on:

Delta = CMJ - SJ

and not separately on SJ_Mean and CMJ_Mean.

This is because the paired t-test is based on the distribution of the within-subject differences.

Show R code 
shapiro_result <- shapiro.test(df$Delta)
shapiro_result

Interpretation of the normality test

The null hypothesis of the Shapiro-Wilk test is that the data are normally distributed.

If p > 0.05, the normality assumption is considered acceptable. If p < 0.05, normality would be questioned.

In this project, the p-value is greater than 0.05, which means that the normality assumption is not violated. This supports the use of a paired t-test for the next step.

Interpretation of the paired t-test

The paired t-test provides several important pieces of information:

  • the t statistic,
  • the degrees of freedom,
  • the p-value,
  • the confidence interval of the mean difference,
  • the estimated mean difference between conditions.

If the p-value is below 0.05, the difference between CMJ and SJ is considered statistically significant.

Here, the result indicates that jump height is significantly greater in the CMJ condition than in the SJ condition.

7.8 Effect size

A statistically significant p-value tells us that a difference exists, but it does not tell us how large that difference is in practical terms.

To address this, we compute Cohen’s d, which provides a standardized effect size.

Show R code 
effect_size <- cohen.d(df$CMJ_Mean, df$SJ_Mean, paired = TRUE)

Interpretation of the effect size

Cohen’s d is commonly interpreted as follows:

  • around 0.2: small effect
  • around 0.5: medium effect
  • around 0.8 or more: large effect

In this project, the effect size is large, which indicates that the difference between SJ and CMJ is not only statistically significant, but also substantial in magnitude.

8. Discussion

8.1 Main findings

The purpose of this project was to compare jump height between Squat Jump (SJ) and Countermovement Jump (CMJ) in athletes with patellar tendinopathy, using the difference between both jump modalities as an indirect functional indicator of stretch-shortening cycle (SSC) contribution.

The statistical analysis showed that jump height was significantly greater in the CMJ condition than in the SJ condition. The mean paired difference between conditions was 3.57 ± 2.02 cm, and the paired t-test demonstrated a statistically significant effect with a large effect size.

8.2 Interpretation of SSC contribution

From a biomechanical perspective, these findings are consistent with the expected contribution of the SSC during vertical jump tasks. Unlike the SJ, the CMJ includes a preparatory eccentric phase before propulsion, allowing the muscle-tendon unit to store and reutilize elastic energy during the concentric phase.

In addition to elastic energy reutilization, the countermovement phase may also enhance performance through neural and mechanical potentiation mechanisms, contributing to greater force production and movement efficiency.

The greater jump height observed in the CMJ condition therefore supports the interpretation that the SSC contributed positively to jump performance in this sample.

8.3 Clinical relevance for patellar tendinopathy

Because all participants presented patellar tendinopathy, these results may provide insight into how explosive lower-limb function is maintained despite tendon pathology.

Interestingly, the expected performance advantage of the CMJ remained present at the group level. This suggests that, despite potential alterations in movement strategies described in previous literature, participants were still able to benefit functionally from the countermovement phase during jumping.

However, these findings should be interpreted cautiously. A greater CMJ height does not necessarily indicate normal tendon function or normal biomechanical behavior. Athletes with patellar tendinopathy may still develop compensatory strategies involving altered joint kinematics, landing mechanics, or force distribution.

Therefore, the SJ-CMJ comparison should be considered an indirect functional indicator of SSC contribution rather than a direct measurement of tendon or neuromuscular function.

8.4 Limitations

Several limitations should be acknowledged in this project.

  • The sample size was relatively small (n = 12).
  • Only one performance variable was analyzed.
  • The SSC was assessed indirectly through jump height difference.
  • No healthy control group was included for comparison.
  • Jump height alone does not fully describe the biomechanics of jumping and landing tasks.

Future analyses could include additional biomechanical variables such as force production, joint kinematics, landing strategy, stiffness, or electromyographic activity in order to better characterize movement adaptations associated with patellar tendinopathy.

9. Conclusion

This project showed that jump height was significantly greater during the Countermovement Jump (CMJ) than during the Squat Jump (SJ) in athletes with patellar tendinopathy.

The mean difference between conditions was 3.57 cm, with a statistically significant paired t-test and a large effect size. These results suggest that the performance advantage associated with the countermovement phase remained present at the group level.

Therefore, the difference between CMJ and SJ can be interpreted as an indirect functional indicator of stretch-shortening cycle contribution. However, this does not exclude the presence of altered movement strategies or compensations related to patellar tendinopathy.
